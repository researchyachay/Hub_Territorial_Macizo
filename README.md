# Hub_Territorial_Macizo
Construcción comunitaria de un Hub Territorial de Productos de Naturaleza y Bioeconomía Circular: integración de Saberes Ancestrales, Biotecnología Agroambiental, Agricultura de Precisión, Conservación de Abejas y Aprovechamiento de Fibras Residuales mediante IAP y Escuelas de Campo (ECAs) para el Bienestar Alimentario y el Relevo Generacional
